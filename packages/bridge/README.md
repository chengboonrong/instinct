# @instinct/bridge

Development-only local WebSocket publisher/viewer. Never connect it to an untrusted/public relay.

> Experimental 0.1.0 alpha package; ESM-only, API unstable and **not published to npm**. Package tarballs are available as CI build artifacts on the Instinct repository.

See the [root README](https://github.com/chengboonrong/instinct) and [alpha install guide](https://github.com/chengboonrong/instinct/blob/chore/installable-alpha-validation/docs/alpha-installation.md).
